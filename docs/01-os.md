### BSoD Driver/Device

#### Disconnect Internet
[**BEFORE**] Setup Windows (OOBE) - [**UNTIL**] Disable the device from Device Manager (steps below)  
Windows Update will downloads driver from Internet that causes BSoD.  

(device name EN: "PCI Simple Communications Controller", "Intel(R) Management Engine Interface"  
JA: "SM バス コントローラー", "PCI シンプル通信コントローラー")

> [!CAUTION] 
> If you didn't disconnect, it causes BSoD immediately after boot (login screen).  
> The recovery below will not work if the BSoD occurs before account creation, as defaultaccount0 is not accessible

Running Windows Update will cause a BSoD even with the device disabled, but that's OK - your PC will restart normally afterwards.

If you have installed the BSoD driver:

1. Wait until boot to recovery. (repeat BSoD)
2. Open command prompt by using the recovery menu
3. Execute `dism /Image:C:\ /Get-Drivers` and find BSoD driver (Hint: System, Intel, heci.inf).
4. Execute `dism /Image:C:\ /Remove-Driver:oem?.inf` to remove it.

*From my experience, the above process may break Windows Update, so you may need to disable the device before setup. (more info needed)*
